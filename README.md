## 🚀 Featured Project

### ShelfGuard

A private mobile-first inventory management application created from a real-world problem I encountered while working in merchandising.

ShelfGuard is designed to help users manage products across multiple stores and keep track of expiration dates.

### Key features

- User authentication
- Multi-store management
- Product CRUD
- EAN, brand and department tracking
- Expiration date tracking
- Product quantity and store location
- Dashboard with inventory metrics
- Configurable expiration notifications
- Free / Pro subscription structure
- Stripe integration

The application is currently private and under testing.
